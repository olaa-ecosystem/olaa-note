# Contributing

## Before changes
1. Read `README.md` and the architecture and PRD documents in `olaa-ecosystem/olaa-platform` (`architecture/`).
2. Confirm the change belongs to this product.
3. Create or update an issue for non-trivial work.

## Branches
- `main`: protected, releasable
- `feat/<short-name>`: feature work
- `fix/<short-name>`: bug fixes
- `docs/<short-name>`: documentation
- `chore/<short-name>`: maintenance

## Pull requests
- Keep PRs focused.
- Explain motivation, scope, test evidence, risks, and rollback notes.
- Do not merge failing checks.
- Never commit secrets, user data, or generated build artifacts.

## Definition of Done
- Scope and architecture respected or approved docs updated.
- Tests added/updated and pass.
- Accessibility, security, and error states considered.
- Documentation updated where relevant.
