# Security Policy

## Reporting
Do not report vulnerabilities in public issues. Contact repository maintainers through a private reporting channel configured for this organization.

## Baseline
- Never commit credentials, tokens, private keys, or production data.
- Validate and authorize every server-side request.
- Treat client input and imported files as untrusted.
- Keep dependencies updated and review security advisories.
- Use least-privilege access.
- Do not log secrets or sensitive personal data.
- Document security-sensitive changes and threat assumptions.

## Status
Private reporting contact and security response SLA must be configured before production launch.
