# Branching and Versioning

## Branches
- `main`: protected, releasable.
- `feat/<slug>`: feature.
- `fix/<slug>`: bug fix.
- `docs/<slug>`: documentation.
- `chore/<slug>`: maintenance.

## Commits
Prefer Conventional Commit style: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.

## Releases
Use tagged releases and maintain a changelog. Versioning policy to be approved before first public/production release.
