# AI Coding Agent Rules

1. Read README, SCOPE, ARCHITECTURE, TECH_STACK, MODULES, SECURITY_BASELINE, DATA_OWNERSHIP, API_CONTRACTS and CODING_STANDARDS before work.
2. Do not invent product requirements or claim placeholder modules work.
3. Do not change approved architecture, dependencies, contracts, data ownership or scope without proposing a change and updating documentation/ADR.
4. Inspect existing files before editing; preserve behavior and data.
5. Work in small, reviewable changes.
6. Never delete/overwrite user data or production data.
7. Never expose secrets.
8. Add/adjust tests and run available checks.
9. Report files changed, commands run, results, risks, incomplete items and next steps.
10. If requirements are ambiguous or destructive actions are needed, stop and ask.
