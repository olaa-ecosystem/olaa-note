# Definition of Done

- [ ] Acceptance criteria met.
- [ ] Scope respected or change approved.
- [ ] Types, lint and tests pass.
- [ ] Error/loading/empty/offline states handled as relevant.
- [ ] Accessibility and responsive behavior checked.
- [ ] Security and privacy implications reviewed.
- [ ] Documentation updated.
- [ ] No secrets or unintended data included.
- [ ] Review and rollback plan included when applicable.
